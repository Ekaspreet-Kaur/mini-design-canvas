# Mini Design Canvas API

Express + TypeScript + MongoDB API for the Mini Design Canvas assignment.

## Endpoints

- `GET /api/health`
- `POST /api/canvases`
- `GET /api/canvases`
- `GET /api/canvases/:id`
- `PUT /api/canvases/:id`
- `DELETE /api/canvases/:id`

Create `backend/.env` from `.env.example` and provide a MongoDB connection string.

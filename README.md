# Mini Design Canvas

A full-stack design canvas application for creating and editing shapes on an interactive canvas.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, React Konva, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript, MongoDB, Mongoose

## Development Status

**Phase 1 complete** — Project structure initialized with Next.js frontend and Express backend. Health endpoint available at `GET /api/health`.
